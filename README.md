# Shifts Windows updates

Public Windows installer artifacts and update metadata for Shifts by Vida.

Download an installer from [Releases](https://github.com/isvidabogdan/vida-shifts-updates/releases).
The installed application checks this repository for updates and asks before restarting to install.

The initial 0.1.0 and 0.1.1 releases are unsigned internal desktop foundation tests.
They are not Windows Authenticode signed and make no SmartScreen trust claim.

This repository contains no application source, VidaUI package archives, credentials, or development logs.
